# Жильё под удалёнку · 9 областей · топ-50 на область

Каталог объявлений OLX, ЛУН, публичных каналов Телеграма и Facebook Marketplace по девяти
областям: Волынь, Ровенщина, Львовщина, Тернопольщина, Прикарпатье, Буковина, **Хмельниччина,
Житомирщина и Винничина** (добавлены 02.09.2026). Закарпатье исключено покупателем.

## Формат каталога (с 2 сентября 2026)

- **Топ-50 на область** — дома и квартиры отдельно, в каждом источнике. Номер на карточке —
  место лота внутри своей области и своего набора.
- **Жёсткое правило: дальше 10 км от ближайшего города лоты не рассматриваются вообще.**
  «Город» — населённый пункт от ~8 тыс. жителей из справочника `scripts/lib9.js`.
- **Близость к городу весит 2:1** к каждой другой категории индекса цена/качество
  (цена за м², площадь, участок / комнаты-этаж-ремонт).
- Лоты с разбором «нам подходит» (закреплённое избранное) не выпадают из каталога
  при пересборках — иначе пересборка стёрла бы метки покупателя.
- **Двойники**: один объект, найденный в двух источниках (совпадают цена ±2% и площадь ±5%,
  та же локация), помечен на обеих карточках бейджем `⇆ ИСТОЧНИК` — клик ведёт на вторую
  карточку и при необходимости сам включает нужные фильтры.
- **Слой промышленности на карте** — полигоны landuse=industrial и quarry из OpenStreetMap,
  агрегированные в ячейки ~4×4 км (`scripts/industry.js` → `scripts/data/industry.json`);
  чем краснее и крупнее пятно, тем больше промышленных площадей. Выключается в легенде.

Состав (готовое): дома OLX 300 · квартиры OLX 145 · дома ЛУН 155 · квартиры ЛУН 23 ·
Телеграм 71 · Фейсбук 3 = **697 лотов**. Лотов с двойником в другом источнике — 203.

## «Получистовая» — отдельный список (с 2 сентября 2026, вечер)

Просьба покупателя: получистовая **не конкурирует с готовым жильём за места в топ-50**, но
собирается **по аналогии** — свой топ-50 на область по домам и квартирам в каждом источнике,
то же правило ≤10 км, близость к городу ×2. На странице идёт отдельным списком со своей шапкой
после готового; сортировка действует внутри каждого списка; фильтр «Готовность» включает и
выключает список целиком.

- **Кандидаты** — то, что готовый отбор отбросил по состоянию: текст «недобудова / під чистову /
  потребує ремонту / без ремонту», параметр OLX «Ремонт: після будівельників / під чистову»,
  фотопроверка «на фото не жилой дом» при таком тексте; ЛУН — флаг `unfinished`; плюс карточки
  прежней страницы (`scripts/data/live-semi.json`, там есть лоты и дешевле $29 тыс.).
- **Класс «что готово»** ставит `semiClass()` в `scripts/lib9.js` по тексту (класс с прежней
  страницы, если есть, надёжнее регэкспа): `floor` этаж готов · `part` одна часть жилая ·
  `while` заезжай и доводи · `repair` жилая, под ремонт · `annex` флигель жилой · `unfin`
  недострой с сетями · `shell` под чистовую, сети заведены (новый класс). Дом без сигнала о
  сетях в набор не попадает — это коробка.
- **Индекс** `semiHouseQuality9 / semiFlatQuality9`: цена за м², площадь, участок (комнаты и
  этаж), вес класса «что готово» (1.0 → 0.3), близость к городу с двойным весом.
- **«К рынку области»** — насколько $/м² ниже медианы готового жилья того же типа в той же
  области (медиана считается по готовому набору при каждой сборке).

Сейчас в наборе **265 лотов**: дома OLX 104 · квартиры OLX 149 · ЛУН 12; по классам —
под чистовую 161, под ремонт 47, часть жилая 23, недострой с сетями 20, этаж 6, флигель 6,
заезжай и доводи 2.

## Карта: метки прямо на карте

Клик по одиночному маркеру (и по группе, которая уже не распадается) открывает карточку:
ссылка на источник, ★ избранное (по кругу зелёная → синяя → золотая → снять), ✕ недоступно,
корзина «удалить из подборки» и стрелка ↓ к карточке в каталоге. Кнопки несут те же
`data-fav / data-unav / data-del`, что и на карточках, поэтому их обрабатывают обработчики
страницы: одно и то же хранилище (`bh:fav`, `bh:dead`, `bh:del`), список и карта
перекрашиваются сразу.

Дома OLX прошли фотопроверку: «готовое» значит, что на фото виден жилой дом, а не коробка,
недострой, план или участок (вердикты — `scripts/data/photo-vet.json`: из 408 кандидатов
280 прошли, 128 отклонены; сетки для проверки собирает `scripts/vet-grid.js`).

## Откуда берётся точка на карте

Точность метки разная, и это сказано в подписи под картой:

1. **Адрес из объявления** — улица, иногда с номером дома, вытащенная из заголовка или описания
   (`scripts/lib-addr9.js`) и геокодированная через Nominatim (`scripts/addr9.js` → `data/addr9.json`).
   Кэш по id лота, повторные сборки в сеть не ходят.
2. **Село из текста** — если в описании назван другой населённый пункт, чем в поле объявления
   («біля Коломиї, с. Ценява»), метка переносится в это село.
3. **Центр населённого пункта** — `data/geocode9.json`, ключ `<нас.пункт>|<область>`: все лоты
   одного села лежат в одной точке, и кластер означает «в одном селе», а не «дома рядом».
4. **Точка OLX (`map`)** — фолбэк: у OLX это zoom 12 и радиус 1–7 км, а у агентств иногда офис
   в другом городе.

Чтобы метка не уехала мимо: адрес из предложения про офис, агентство или телефон не берётся;
фразы-ориентиры («15 км від міста Рівне», «біля Снятина») адресом не считаются; ответ Nominatim
принимается, только если название улицы совпадает с искомым (с поправкой на «і/и» и падежи)
и точка не дальше 12 км от центра населённого пункта, а перенос в другое село — не дальше 60 км.

Уточнение метки меняет и отбор: «км до города» считается от неё, поэтому лот, у которого
в описании назван свой посёлок («будинок в селі Зубків, 19 км до Шептицького»), после переноса
честно выходит за правило «не дальше 10 км» и уходит из каталога, а его место занимает следующий
по индексу.

Адрес перед выездом всё равно уточняется у продавца: каталог для этого не источник.

## Пересборка

```bash
node scripts/olx-harvest9.js houses && node scripts/olx-harvest9.js flats  # OLX, бисекция цены
node scripts/geocode9.js          # Nominatim, 1 запрос/сек (центры населённых пунктов)
node scripts/lun9-scrape.js       # ЛУН новых городов (браузер br, CDP)
node scripts/lun9-geocode.js
node scripts/tg9.js               # Телеграм новых городов (t.me/s)
node scripts/fetch-shapes9.js     # контуры областей (+полигоны для привязки)
node scripts/industry.js          # промзоны OSM Overpass (кэш в data/industry-raw)
node scripts/extract-live.js      # получистовая и координаты из текущего index.html
node scripts/addr9.js             # адреса из текстов объявлений → точные метки
node scripts/units9.js            # отбор, топ-50, дубли → data/units9.json + vet-need.json
node scripts/vet-grid.js 60       # сетки фотопроверки; вердикты — vet-apply.js
node scripts/views9.js && node scripts/market9.js && node scripts/market-index9.js
node scripts/thumbs9.js
node scripts/render9.js           # → index.html (Pages) и scripts/best-houses9.html (артефакт)
```

Правила, которые нельзя нарушать:

1. **Потолок OLX = 1000**: любой сбор выдачи — только через рекурсивную бисекцию цены
   (`olx-harvest9.js`); одиночный фильтр молча теряет хвост.
2. **excluded.json применяется до отбора топа**, а не после: лоты, снятые покупателем
   корзиной, не возвращаются никогда, их места добираются следующими по индексу.
3. dead.json обновляет GitHub Actions раз в сутки (`scripts/check-dead.mjs`).
4. Старые сборки (запад, до 02.09.2026) живут в scratchpad-сессиях — пути прописаны
   в `scripts/units9.js`; их кэши (геокод, рынок, миниатюры, детали ЛУНа) переиспользуются.

## Индексы

| Индекс | Что показывает |
|---|---|
| **Цена/качество** (42–97) | Близость к городу (вес ×2), цена за м², площадь, участок / комнаты-этаж-ремонт |
| **Просмотров в день** | Спрос по счётчику OLX (среднее за жизнь объявления); глаз открывается от 30/день |
| **Дата размещения** | Настоящая (`createdTime`), а не дата поднятия, которую показывает OLX |
| **Км до города** | По прямой до ближайшего города из справочника; каталог режется по ≤10 км |
| **Рынок: продать · сдать** | Ликвидность в радиусе 10 км и рынок аренды в самом населённом пункте |
| **Что готово / к рынку области** | Только «получистовая»: какая часть жилая (или что это коробка под чистовую с сетями) и насколько м² дешевле медианы готового того же типа в области |

Данные собраны 02.09.2026. Цены, просмотры и наличие объявлений меняются ежедневно.
