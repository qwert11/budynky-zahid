# Лучшие дома Западной Украины · $30–40 тыс.

Каталог готовых к проживанию домов из объявлений OLX.ua по восьми регионам Западной Украины
(Ивано-Франковск, Львов, Тернополь, Черновцы, Ужгород, Мукачево, Луцк, Ровно + Волынь шире).

Из ~520 объявлений отобрано **150**: без недостроев, коробок «под чистовую», аварийных и
разваленных построек. Критерий жёсткий: если на фото кирпич или блоки без отделки, либо
самого дома на фото нет — объявление в список не попадает. Во втором визуальном проходе
(26.08.2026) по этому правилу убрано 22 объявления.

## Что внутри

- **Каталог из 150 домов** — однородный список: фото, индексы, ссылка на OLX.
- **Сортировка** — всегда лучшее сверху: индекс цена/качество, дешевле, выгоднее за м²,
  больше дом, больше участок, ближе к городу, выше спрос, больше шансов на торг.
- **Избранное** — звёздочка на любом доме; фильтр прячет из списка и с карты всё остальное,
  избранные на карте — крупной жёлтой звездой. Хранится в браузере (localStorage, ключ `bh:fav`)
  **по ID объявления OLX** плюс снимок (заголовок, цена, ссылка), поэтому при обновлении каталога
  звёзды не съезжают на другие дома, а выпавшие из отбора показываются отдельным блоком со ссылками.
- **Кнопка «вверх»** — появляется после первого экрана.
- **Интерактивная карта** — кластеры с количеством домов, контуры и названия областей,
  слой населённости, границы городов-стотысячников; клик по одиночному маркеру открывает объявление.
  На компьютере зум — Ctrl + колесо; на телефоне — щипок двумя пальцами,
  кнопка ⛶ разворачивает карту на весь экран (там карта тянется одним пальцем).

## Индексы

| Индекс | Что показывает |
|---|---|
| **Цена/качество** (0–100) | Цена за м², состояние по фото и описанию, отопление, санузел, ремонт, площадь, участок, близость к городу |
| **Цена** | Цена из объявления, в долларах |
| **Просмотров в день** | Спрос: высокий — лот горячий; низкий при долгом сроке — вероятен торг. Счётчик OLX накопительный и не сбрасывается при поднятии, поэтому это среднее за всю жизнь объявления. Плашка залита по спросу: 0 нейтральная, 30 в день жёлтая, 100+ красная |
| **Дата размещения** | Настоящая дата публикации (`createdTime`) и срок продажи. В интерфейсе OLX эта дата не выводится — там показана дата последнего поднятия, поэтому дом, висящий два года, выглядит свежим |
| **Км до города** | Расстояние по прямой до ближайшего города (учитывается его размер). Плашка залита по расстоянию: 0 км — нейтральная, к 10 км желтеет, дальше краснеет, 60+ км — полностью красная |
| **Цена за м²** | Стоимость квадратного метра дома |

Данные на 25 августа 2026. Цены, просмотры и наличие объявлений меняются ежедневно.
