# Лучшие дома Западной Украины · $30–40 тыс.

Каталог готовых к проживанию домов из объявлений OLX.ua по восьми регионам Западной Украины
(Ивано-Франковск, Львов, Тернополь, Черновцы, Ужгород, Мукачево, Луцк, Ровно + Волынь шире).

Из ~520 объявлений отобрано **150**: без недостроев, домов «под чистовую», аварийных и
разваленных построек. Каждый проверен по фотографиям и параметрам объявления.

## Что внутри

- **Топ-10** — детальные карточки: три фото, карта расположения, плюсы и минусы.
- **Каталог из 150 домов** — фото, индексы, ссылки на OLX.
- **Сортировка** — по индексу цена/качество, цене, цене за м², площади дома и участка,
  просмотрам в день, всего просмотрам, близости к городу и сроку размещения.
- **Избранное** — звёздочка на любом доме; список хранится в браузере (localStorage) и
  фильтруется одной кнопкой; избранное подсвечивается и на карте.
- **Интерактивная карта** — кластеры с количеством домов, слой населённости, границы
  городов-стотысячников; клик по одиночному маркеру открывает объявление.
  На компьютере зум — Ctrl + колесо; на телефоне — щипок двумя пальцами,
  кнопка ⛶ разворачивает карту на весь экран (там карта тянется одним пальцем).

## Индексы

| Индекс | Что показывает |
|---|---|
| **Цена/качество** (0–100) | Цена за м², состояние по фото и описанию, отопление, санузел, ремонт, площадь, участок, близость к городу |
| **Цена** | Цена из объявления, в долларах |
| **Просмотров в день** | Спрос: высокий — лот горячий; низкий при долгом сроке — вероятен торг |
| **Км до города** | Расстояние по прямой до ближайшего города (учитывается его размер) |
| **Цена за м²** | Стоимость квадратного метра дома |

Данные на 25 августа 2026. Цены, просмотры и наличие объявлений меняются ежедневно.
